# Controls and hotkeys

## Keyboard gameplay mapping

| Function | Key |
|---|---|
| X1 / Up | Arrow Up |
| X2 / Right | Arrow Right |
| X3 / Down | Arrow Down |
| X4 / Left | Arrow Left |
| Y1 / Up | W |
| Y2 / Right | D |
| Y3 / Down | S |
| Y4 / Left | A |
| A | Z |
| B | X |
| START | C |

## Capture hotkeys

| Function | Key |
|---|---|
| PNG screenshot | P |
| Start/stop GIF recording | G |
| PNG + Mesen MSS ZIP | M |

These hotkeys do not overlap with the default gameplay mapping.

## Touch controls

The mobile UI exposes all physical WonderSwan gameplay controls simultaneously:

- X1-X4
- Y1-Y4
- A
- B
- START
- Fast Forward toggle

Touch input uses pointer events and supports simultaneous multi-touch presses.

## Gamepad

The emulator supports the browser Gamepad API for compatible Bluetooth/USB controllers. The exact platform button numbering can vary between Android/browser/controller combinations.
