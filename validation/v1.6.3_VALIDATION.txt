WonderSwan Mobile Emulator Pro v1.6.3 - Capture Bundle & Hotkeys
================================================================

FEATURES ADDED
--------------
1. New independent capture function: PNG + Mesen MSS in a single ZIP.
   - Freezes emulation while PNG and MSS are produced, so both correspond to the same emulation instant.
   - ZIP contains exactly two files: <rom>_<frame>.png and <rom>_<frame>.mss.
   - MSS uses the existing Mesen 2.1.1 / format v4 bridge.
   - ZIP is generated fully offline with an internal STORE-mode ZIP writer and CRC32.

2. Keyboard mapping
   - X1/X2/X3/X4: ArrowUp / ArrowRight / ArrowDown / ArrowLeft
   - Y1/Y2/Y3/Y4: W / D / S / A
   - A: Z
   - B: X
   - START: C

3. Capture hotkeys (non-overlapping with gameplay keys)
   - P: PNG screenshot
   - G: start/stop animated GIF
   - M: PNG + MSS ZIP bundle

4. UI visibility
   - P/G/M badges are visible directly on capture buttons.
   - A dedicated "Teclado / Hotkeys" card lists all gameplay mappings and capture hotkeys.
