# Security

## Scope

The emulator is designed to run completely offline. It processes untrusted local files including ROMs, firmware ZIPs, battery saves, and Mesen save states.

## Reporting

Please open a GitHub issue for reproducible crashes, malformed-file handling problems, data-loss bugs, or cases where the release unexpectedly attempts network access.

Do not attach copyrighted commercial ROMs or BIOS files to public issues. Prefer hashes, filenames, file sizes, screenshots, or minimal homebrew repro cases.

## Browser storage

ROMs, firmware, preferences, save slots, and battery data can be persisted locally through browser storage. Clearing site data will remove those stored copies unless they have been exported first.
